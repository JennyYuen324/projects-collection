# SQL Practice and DataCamp Projects

This repository collects all of my SQL exercises, queries, and mini-projects completed during my learning process on DataCamp and self-study. It serves as a record of my progress from basic queries to more complex analysis tasks.

## 📁 Structure
Each `.sql` file represents a different exercise or project. Files are named clearly to indicate their topics.

## 🎯 Goals
- Consolidate and organize my SQL practice in one place  
- Demonstrate understanding of fundamental SQL operations  
- Track progress and improvements over time  

## 🧰 Topics Covered
- Filtering and selection (`WHERE`, `BETWEEN`, `LIKE`)  
- Aggregation and grouping (`GROUP BY`, `HAVING`)  
- Sorting and limiting results (`ORDER BY`, `LIMIT`)  
- Calculated columns and functions (`AVG`, `COUNT`, `ROUND`)  
- Joins and subqueries (in later exercises)

## 📈 Next Steps
This repository will keep expanding as I complete more projects and explore advanced SQL topics.
